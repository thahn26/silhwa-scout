# 실화탐사대 (아이템 레이더) — 노트북 앱

커뮤니티 인기글·많이 본 뉴스를 모아 <실화탐사대> 아이템이 될 만한 순서로 정렬해 줍니다.

## 여는 법
응용 프로그램 폴더의 `실화탐사대`를 여세요. Claude 채점은 Claude 데스크톱 앱에 든 Claude Code
(요금제 로그인)를 씁니다. 오른쪽 위 알약 버튼이 `Claude 연결됨`이면 준비 끝입니다.

## 흐름
1. **수집** — 앱을 켜 두면 1시간마다(설정에서 변경) 19개 목록을 읽습니다. `지금 수집`으로 바로 읽을 수도 있습니다.
2. **예비 점수** — 커뮤니티 안에서의 반응(조회·추천·댓글) 순위 + 사건·사고 키워드로 0~100점을 매깁니다.
3. **AI 채점** — 예비 점수 상위 40건(커뮤니티별로 고르게)의 본문 앞부분까지 Claude가 읽고
   아이템성 점수·분류·이유·취재 포인트를 붙입니다. 채점 기준은 설정에서 고칠 수 있습니다.
4. **찜·메모** — ☆로 찜하고 상태(검토중/취재후보/보류/탈락)와 메모를 남깁니다. 제목을 누르면 본문과 `AI 심층 분석`.
5. **보고서** — 찜한 아이템을 체크하고 `보고서 만들기` → 회의용 마크다운 보고서(복사/.md 저장).
6. **웹검색** — 스레드·국민동의청원·인스티즈·뽐뿌처럼 직접 못 읽는 곳은 Claude 웹검색으로 찾아옵니다(3~6분).

## 수집 대상
| 묶음 | 커뮤니티 |
|---|---|
| 사연·폭로 | 네이트판(실시간·일간 랭킹), 더쿠 HOT, 82쿡 많이 읽은 글 |
| 남초·이슈 | 디시 실베, 에펨 포텐, 루리웹 베스트, 클리앙 모공, 엠팍 불펜, 오늘의유머 베오베, 개드립, 웃긴대학, SLR 인기글, 보배드림 유머게시판 |
| 사고·피해 | 보배드림 베스트·교통사고·자유게시판, 블라인드 토픽 베스트 |
| 뉴스·청원 | 네이버 많이 본 뉴스·댓글 많은 뉴스(언론사별 상위 2개) |
| 웹검색(AI) | 스레드, 국민동의청원, 인스티즈, 뽐뿌 |

사이트 구조가 바뀌어 한 곳이 `실패`로 뜨면 `sources.py`의 해당 `parse_*` 함수만 고치면 됩니다.
`python3 sources.py dcbest` 처럼 실행하면 그 사이트만 시험 수집합니다.

## 폴더 구성
- `web/` — 화면(index.html, app.js)
- `server.py` — 로컬 서버(127.0.0.1:8766), 수집 스케줄·점수·Claude 호출. 창을 닫고 10분 뒤 스스로 꺼집니다.
- `sources.py` — 커뮤니티별 수집기와 본문 추출
- `minisoup.py` — 설치 없이 쓰는 작은 HTML 파서
- `launch.sh` / `make-app.sh` — 실행 / 앱으로 설치. **파일을 고친 뒤에는 `./make-app.sh`를 다시 실행해야 앱에 반영됩니다.**

## 데이터
`~/Library/Application Support/SilhwaScout/` — posts.json(7일 보관, 찜한 글은 계속), saved.json, reports/, config.json

## 윈도우 설치 파일
`main` 브랜치에 올리면 GitHub Actions(`.github/workflows/windows-installer.yml`)가 윈도우 서버에서
설치 없는 파이썬을 받아 앱 서버를 실제로 켜서 수집까지 시험하고, `Silhwatamsadae_Setup_1.0.N.exe`를 만들어 **Releases**에 올립니다.
- 설치 스크립트: `windows/installer.iss` (Inno Setup, 관리자 암호 없이 `%LOCALAPPDATA%\Programs\SilhwaScout`에 설치)
- 실행기: `windows/launcher.pyw` — 서버를 켜고 Edge 앱 창을 연다. `--stop`이면 서버를 끈다.
- 윈도우 데이터: `%APPDATA%\SilhwaScout`
- 서명 인증서가 없어 처음 실행 때 "Windows의 PC 보호" 창이 뜬다 → [추가 정보] → [실행].
